# Token Launch Radar v3

A make.fun token-radar-01 entry: an implied-value model board over token protocols — fitted from the snapshot itself, with a dense dashboard. Deterministic: every date comes from the snapshot, no wall clock, no randomness in the output path.

## Run

`node main.ts` — fits the model on the provided snapshot and writes the board, dashboard, and `dossier.json` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
